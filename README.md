Lern-project-3. Лэндинг магазина текстиля.


О проекте

В этом проекте я продолжил учиться верстать. Стек HTML/CSS/SCSS/JS. С помощью JS были реализованы следующие фичи: переключение контента в разделе "Про технологии" ; для мобильных устройств слайдер в "Наши тарифы" и работу бургера и всплывающего меню; яндекс-карты в "Область охвата"; плавный скролл страницы и простейшая анимация. Дизайн разработала Евгения Иванайская (https://vk.ru/ohjeni). Код доступен по ссылке: https://github.com/ivanays/lern-project-2.local. Создан в 2022 году. 


Быстрый запуск

1. Загрузите и установите локальный сервер OSPanel для ос Windows (https://ospanel.io/download/). 
2. Содержимое репозитория lern-project-2.local (https://github.com/ivanays/lern-project-3.local) скопируйте в корневую папку lern-project-3.local локального хостинга OSPanel.
3. Запустите локальный сервер от имени администратора. Выберите "lern-project-3.local" во вкладе "Мои проекты" админ-панели сервера OSPanel.
